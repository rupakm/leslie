Definition 1Probabilistic Labelled Transition System

A probabilistic labelled transition system (PLTS) is a tuple \(\mathcal{P}:= (Q,q_\star ,L,T)\) where \(Q\) is a (countable) set of states, \(q_\star \in Q\) is a set of initial states, \(L\) is a (countable) set of labels and \(T \subseteq Q \times (L \cup \{ \tau \} ) \times \mathcal{D}(Q)\) is a set of probabilitsic transitions.

Definition 2Partial Probabilistic Execution

Given \(\mu \in \mathcal{D}(Q)\) and \(s \in Sch\), one can define a partial probabilistic execution induced by \((\mu ,s)\) as the function \(\mathfrak {e}_{\mu ,s}\) from \(\mathcal{E}^*\) to \([0,1]\) such that if \(e \in Q\) then \(\mathfrak {e}_{\mu ,s} = \mu (e)\); else, \(e = e'.l.q\) and \(\mathfrak {e}_{\mu ,s}(e) = \mathfrak {e}_{\mu ,s}(e')\cdot \sum _{t \in T \mid lbl(t) = l}s(e')(t)\cdot out(t)(q)\).

Definition 3Parallel Composition of PLTS

Given \(\mathcal{P}\) and \(\mathcal{P}'\) two PLTSs and \(S \subseteq L \cup L'\), the composed PLTS \(\mathcal{P}\parallel _S \mathcal{P}'\) is defined as \((Q \times Q', (q_\star , q_\star '), L \cup L', T \parallel _S T')\) where \(((q,q'), l, \mu '') \in T \parallel _S T'\) if and only if

  • \(l \in S\) and there exist \((q,l,\mu ) \in T\) and \((q',l,\mu ') \in T'\) such that \(\mu \otimes \mu ' = \mu ''\); or

  • \(l \not\in S\) and there exists \((q,l,\mu ) \in T\) such that \(\mu \otimes \delta _{q'} = \mu ''\); or

  • \(l \not\in S\) and there exists \((q',l,\mu ') \in T'\) such that \(\delta _q \otimes \mu ' = \mu ''\).

Definition 4Probabilistic Forward Simulation

Given \(\mathcal{P}\) and \(\mathcal{P}'\) two PLTSs, a probabilistic forward simulation of \(\mathcal{P}\) by \(\mathcal{P}'\) is a relation \(\mathcal{S}\subseteq Q \times \mathcal{D}(Q')\) such that \((q_\star ,\delta _{q_\star '}) \in \mathcal{S}\) and, for all \((q,\mu ') \in \mathcal{S}\) and \((q,l,\mu ) \in T\); there exists \(\mu ' \xRightarrow {l} \mu ''\) such that \((\mu ,\mu '') \in \mathcal{D}(\mathcal{S})\).

Definition 5Weak Simulation

Given \(\mathcal{P}\) and \(\mathcal{P}'\) two LTSs, a weak simulation of \(\mathcal{P}\) by \(\mathcal{P}'\) is a relation \(\mathcal{S}\subseteq Q \times Q'\) such that \((q_\star ,q_\star ') \in \mathcal{S}\) and, for all \((q,q') \in \mathcal{S}\) and \((q,l,p) \in T\); there exists \(q' \xRightarrow {l} p'\) such that \((p,p') \in \mathcal{S}\).

Definition 6Maximal Weak Simulation

Given two PLTSs \(\mathcal{P}\) and \(\mathcal{P}'\), a weak simulation \(\mathcal{S}\) of \(\mathcal{P}\) by \(\mathcal{P}'\) is said to be maximal if, for all \((q,q') \in \mathcal{S}\), if \(q\) weakly diverges then \(q'\) weakly diverges.

Definition 7Progressive Weak Simulation

Given two PLTSs \(\mathcal{P}\) and \(\mathcal{P}'\), a weak simulation \(\mathcal{S}\) of \(\mathcal{P}\) by \(\mathcal{P}'\) is said to be progressive if

  • for all \((q,q') \in \mathcal{S}\), if \(q\) is a deadlock then \(q'\) weakly diverges.

  • there exists \({\lt} \subseteq Q \times Q\) well-founded such that, for all \((q,q') \in \mathcal{S}\) and \((q,l,p) \in T\), if \((q,l,q')\) is elided by \(\mathcal{S}\) then \(q {\gt} p\) or \(q'\) weakly diverges.

Protocol 2

Concrete implementation. Round-based protocol combining Graded Binding Crusader Agreement (GBCA) with a Weak Common Coin (WCC). Each round, the process refines its bit through GBCA and tosses a coin via WCC; it adopts the coin if GBCA was undecided (\(b = \bot \)) and otherwise decides on \(b\) when GBCA returned the highest grade \(A\), while continuing to run to help the others terminate.

Protocol 10

Concrete implementation. Requires \(|Id|\) instances of BRB and \(|Id|^2\) instances of AVSS. Each process \(id\) draws a fresh secret \(x_{id'}\) for every \(id' \in Id\) and shares it through an AVSS instance, then uses its own BRB to publish the set \(S\) of dealers it received shares from. A process is assigned a value once it has collected, for each entry of the committed set \(S'\), the corresponding AVSS sharing return; the retrieved value is the sum of the AVSS reconstructions.

Ideal implementation.
