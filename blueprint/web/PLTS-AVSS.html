Encoding of ABA State: \(call \in \{ 0,1,\bot \} ^{[n]}; ret \in \mathbb {B}^{[n]}; bind, val \in \{ 0,1,\bot \} ; coin \in \{ 0,1,\bot ,\top \} ; F \subseteq [n]\) Label: \(\{ \text{call}(id,b), \text{return}(id,b), \text{fail}(id) \mid id \in [n], b \in \mathbb {B}\} \) Input: \(\{ \text{call}(id,b), \text{fail}(id) \mid id \in [n], b \in \mathbb {B}\} \) Fairness: all transitions are fair except those labelled by fail and the call loops Initial: \(call = \bot ^{[n]}; ret = \bot ^{[n]}; bind = \bot ; out = \bot ; val = \bot ; F = \emptyset \) \(call[id] = \bot \wedge bind = \bot \xrightarrow {\text{call}(id,b)} call[id] = b\) \(\top \xrightarrow {\text{call}(id,b)} \top \) loop for input-enabledness \(|\{ id \in [n] \setminus F \mid call[id] \ne \bot \} \cup F| \ge n-f \wedge \forall id \in [n] \setminus F, call[id] \ne b \xrightarrow {\tau } call = \bot ^{[n]} \wedge bind = 1-b \wedge val = 1-b \wedge coin = \bot \) \(|\{ id \in [n] \setminus F \mid call[id] \ne \bot \} \cup F| \ge n-f \wedge \exists id, id' \in [n] \setminus F, call[id] = 1 \wedge call[id'] = 0 \xrightarrow {\tau } call = \bot ^{[n]} \wedge bind = 1-b \wedge coin = \bot \) \(call = \bot ^{[n]} \wedge bind \ne \bot \xrightarrow {\tau } coin = 1 \text{ with probability } \epsilon ; 0 \text{ with probability } \epsilon ; \top \text{ otherwise}\) \(call[id] = \bot \wedge bind = coin \xrightarrow {\tau } call[id] = bind\) \(call[id] = \bot \wedge bind \ne coin \xrightarrow {\tau } call[id] = b\) \(b \in \mathbb {B}\) \(val = b \wedge ret[id] = \bot \xrightarrow {\text{return}(id,b)} ret[id] = \top \) \(id \not\in F \wedge |F| {\lt} f \xrightarrow {\text{fail}(id)} F = F \cup \{ id\} \) \(\top \xrightarrow {\text{fail}(id)} \top \) loop for input-enabledness

Encoding of GBCA State: \(call \in \{ 0,1,\bot \} ^{[n]}; ret \in \mathbb {B}^{[n]}; bind, grade \in \{ 0,1,\bot \} ; F \subseteq [n]\) Label: \(\{ \text{call}(id,b), \text{return}(id,x,b), \text{fail}(id) \mid id \in [n], x \in (\mathbb {B}\times \{ A,B\} )\cup \{ (\bot ,C)\} , b \in \mathbb {B}\} \) Input: \(\{ \text{call}(id,b), \text{fail}(id) \mid id \in [n], b \in \mathbb {B}\} \) Fairness: all transitions are fair except those labelled by fail and the call loops Initial: \(call = \bot ^{[n]}; ret = \bot ^{[n]}; bind = \bot ; grade = \bot ; F = \emptyset \) \(call[id] = \bot \xrightarrow {\text{call}(id,b)} call[id] = b\) \(\top \xrightarrow {\text{call}(id,b)} \top \) loop for input-enabledness \(|\{ id \in [n] \setminus F \mid call[id] \ne \bot \} \cup F| \ge n-f \wedge \exists id \in [n] \setminus F, call[id] = b \wedge bind = \bot \xrightarrow {\tau } bind = b\) \(bind \ne \bot \wedge \exists id \in [n] \setminus F, call[id] = 1-bind \wedge ret[id] = \bot \xrightarrow {\text{return}(id,(bind,B),bind)} ret[id] = \top \) \(bind \ne \bot \wedge grade \in \{ \bot ,1\} \wedge ret[id] = \bot \xrightarrow {\text{return(id,(bind,A),bind)}} grade = 1 \wedge ret[id] = \top \) \(bind \ne \bot \wedge \exists id \in [n] \setminus F, call[id] = 1-bind \wedge grade \in \{ \bot ,0\} \wedge ret[id] = \bot \xrightarrow {\text{return}(id,(\bot ,C),bind)} grade = 0 \wedge ret[id] = \top \) \(id \not\in F \wedge |F| {\lt} f \xrightarrow {\text{fail}(id)} F = F \cup \{ id\} \) \(\top \xrightarrow {\text{fail}(id)} \top \) loop for input-enabledness

Encoding of WCC State: \(call, ret \in \mathbb {B}^{[n]}; val \in \{ 0,1,\bot ,\top \} ; guess \in \{ 0,1,\bot \} , F \subseteq [n]\) Label: \(\{ \text{call}(id), \text{return}(id,b), \text{fail}(id), \text{guess}(b) \mid id \in [n], b \in \mathbb {B}\} \) Input: \(\{ \text{call}(id), \text{fail}(id) \mid id \in [n]\} \) Fairness: all transitions are fair except those labelled by fail and the call loops Initial: \(call = \bot ^{[n]}; ret = \bot ^{[n]}; val = \bot ; F = \emptyset \) \(call[id] = \bot \xrightarrow {\text{call}(id)} call[id] = \top \) \(\top \xrightarrow {\text{call}(id)} \top \) loop for input-enabledness \(|\{ id \in [n] \setminus F \mid call[id] \ne \bot \} \cup F| {\gt} f \wedge val = \bot \xrightarrow {\tau } val = 0\) with probability \(\epsilon \); 1 with probability \(\epsilon \); \(\top \) otherwise \(val \in \{ b,\top \} \wedge ret[id] = \bot \xrightarrow {\text{return}(id,b)} ret[id] = \top \) \(b \in \mathbb {B}\) \(id \not\in F \wedge |F| {\lt} f \xrightarrow {\text{fail}(id)} F = F \cup \{ id\} \) \(\top \xrightarrow {\text{fail}(id)} \top \) loop for input-enabledness \(val = \bot \wedge guess = \bot \xrightarrow {\text{guess}(b)} guess = b\)

Encoding of Gather State: \(call \in (X\cup \{ \bot \} )^{[n]}; ret \in \mathbb {B}^{[n]}; bind, F \subseteq [n]\) Label: \(\{ \text{call}(id,x), \text{return}(id,g,bind), \text{fail}(id) \mid id \in [n], x \in X, g \in [n] \rightharpoonup X, bind \subseteq [n]\} \) Input: \(\{ \text{call}(id,x), \text{fail}(id) \mid id \in [n], x \in X\} \) Fairness: all transitions are fair except those labelled by fail and the call loops Initial: \(call = \bot ^{[n]}; ret = \bot ^{[n]}; bind = \emptyset ; F = \emptyset \) \(call[id] = \bot \xrightarrow {\text{call}(id,x)} call[id] = x\) \(\top \xrightarrow {\text{call}(id,x)} \top \) loop for input-enabledness \(call[id] = \bot \wedge id \in F \xrightarrow {\tau } call[id] = x\) \(|\{ id \in [n] \mid call[id] \ne \bot \} | {\gt} n-f \wedge bind = \emptyset \wedge S \subseteq \{ id \in [n] \mid call[id] \ne \bot \} \xrightarrow {\tau } bind = S\) \(bind \ne \bot \wedge ret[id] = \bot \wedge g \text{ is defined on } bind \wedge g \text{ agrees with } call \xrightarrow {\text{return}(id,g,bind)} ret[id] = \top \) \(id \not\in F \wedge |F| {\lt} f \xrightarrow {\text{fail}(id)} F = F \cup \{ id\} \) \(\top \xrightarrow {\text{fail}(id)} \top \) loop for input-enabledness
