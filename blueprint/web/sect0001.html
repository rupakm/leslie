0.1 Preliminaries

0.1.1 Traditionnal Framework

Definition 1 Probabilistic Labelled Transition System
#

Lean declarations

  • PLTS

A probabilistic labelled transition system (PLTS) is a tuple \(\mathcal{P}:= (Q,q_\star ,L,T)\) where \(Q\) is a (countable) set of states, \(q_\star \in Q\) is a set of initial states, \(L\) is a (countable) set of labels and \(T \subseteq Q \times (L \cup \{ \tau \} ) \times \mathcal{D}(Q)\) is a set of probabilitsic transitions.

A partial execution of \(\mathcal{P}\) is sequence \(q_0.l_0.q_1.l_1\cdots \in (Q.L)^*.Q \cup (Q.L)^\omega \) such that, for all \(n \in \mathbb {N}\), there exists \(\mu _n \in \mathcal{D}(Q)\) such that \((q_n,l_n,\mu _n) \in T\) and \(q_{n+1} \in \bar\mu \). The set of finite executions is denoted \(\mathcal{E}^*\). A partial execution is called an execution if \(q_0 = q_\star \). The trace of a partial execution is its projection to \(L\). The set of traces of \(\mathcal{P}\) is denoted \(\mathcal{T}\). A scheduler \(s\) is function from \(\mathcal{E}^*\) to \(\mathcal{D}(T \cup \{ \bot \} )\) such that, for all \(e \in \mathcal{E}^*\) and \(t \in \bar{s(e)}\), \(t = \bot \) or \(src(t) = last(e)\). The set of schedulers is denoted as \(Sch\).

Definition 2 Partial Probabilistic Execution
#

Lean declarations

  • Partial Probabilistic Execution

Given \(\mu \in \mathcal{D}(Q)\) and \(s \in Sch\), one can define a partial probabilistic execution induced by \((\mu ,s)\) as the function \(\mathfrak {e}_{\mu ,s}\) from \(\mathcal{E}^*\) to \([0,1]\) such that if \(e \in Q\) then \(\mathfrak {e}_{\mu ,s} = \mu (e)\); else, \(e = e'.l.q\) and \(\mathfrak {e}_{\mu ,s}(e) = \mathfrak {e}_{\mu ,s}(e')\cdot \sum _{t \in T \mid lbl(t) = l}s(e')(t)\cdot out(t)(q)\).

A partial probabilistic execution is called a probabilistic execution if it is induced by a pair \((\mu ,s)\) such that \(\mu = \delta _{q_\star }\). Partial probabilistic execution induce a measure on the \(\sigma \)-filed induced by cones of partial executions and the trace function is measurable from the \(\sigma \)-field induced by cones of partial executions to the one induced by cones of traces. Thus, \(\mathfrak {t}_{\mu ,s} = tr^{-1}\circ \mathfrak {e}_{\mu ,s}\) is well-defined and called a trace distribution. The set of achievable trace distribution by \(\mathcal{P}\) is defined as those induced by a probabilistic execution of \(\mathcal{P}\) and denoted \(tdist(\mathcal{P})\). The trace distribution pre-order \(\mathcal{P}\subseteq ^t \mathcal{P}'\) is defined by \(tdist(\mathcal{P}) \subseteq tdist(\mathcal{P}')\).

Definition 3 Parallel Composition of PLTS
#

Lean declarations

  • Parallel Composition

Given \(\mathcal{P}\) and \(\mathcal{P}'\) two PLTSs and \(S \subseteq L \cup L'\), the composed PLTS \(\mathcal{P}\parallel _S \mathcal{P}'\) is defined as \((Q \times Q', (q_\star , q_\star '), L \cup L', T \parallel _S T')\) where \(((q,q'), l, \mu '') \in T \parallel _S T'\) if and only if

  • \(l \in S\) and there exist \((q,l,\mu ) \in T\) and \((q',l,\mu ') \in T'\) such that \(\mu \otimes \mu ' = \mu ''\); or

  • \(l \not\in S\) and there exists \((q,l,\mu ) \in T\) such that \(\mu \otimes \delta _{q'} = \mu ''\); or

  • \(l \not\in S\) and there exists \((q',l,\mu ') \in T'\) such that \(\delta _q \otimes \mu ' = \mu ''\).

The trace distribution pre-order is not stable by \(\parallel _S\): \(\mathcal{P}\subseteq ^t \mathcal{P}'\) does not imply \(\mathcal{P}\parallel _S \mathcal{P}'' \subseteq ^t \mathcal{P}' \parallel _S \mathcal{P}''\) [ Seg95 ] . Thus, the largest pre-order included in \(\subseteq ^t\) stable by \(\parallel _S\) is called the trace distribution pre-congruence and is denoted \(\sqsubseteq ^t\).

Let \(R \subseteq A \times \mathcal{D}(B)\), the probabilistic lifting of \(R\), denoted \(\mathcal{D}(R)\), is defined as \((\mu _A,\mu _B) \in \mathcal{D}(R)\) if and only if there exists \(w : R \rightarrow [0,1]\) such that \(\mu _A = a \mapsto \sum _{\mu \in \mathcal{D}(B)}w(a,\mu )\) and \(\mu _B = \sum _{(a, \mu ) \in R}w(a,\mu )\cdot \mu \). If \(s \in Sch\) terminates almost-surely from \(\mu \), (i.e. \(\sum _{e \in \mathcal{E}^*} \mathfrak {e}_{\mu ,s}(e)\cdot s(e)(\bot ) = 1\)) then \(\mathfrak {q}_{\mu ,s} = last^{-1}\circ \mathfrak {e}_{\mu ,s}\) is a well-defined probability distribution over states. We denote \(\mu \xRightarrow {l} \mu '\) if and only if there exists \(s \in Sch\) such that \(\delta _l = \mathfrak {t}_{\mu ,s}\) and \(\mu ' = \mathfrak {q}_{\mu ,s}\).

Definition 4 Probabilistic Forward Simulation
#

Lean declarations

  • Probabilistic Forward Simulation

Given \(\mathcal{P}\) and \(\mathcal{P}'\) two PLTSs, a probabilistic forward simulation of \(\mathcal{P}\) by \(\mathcal{P}'\) is a relation \(\mathcal{S}\subseteq Q \times \mathcal{D}(Q')\) such that \((q_\star ,\delta _{q_\star '}) \in \mathcal{S}\) and, for all \((q,\mu ') \in \mathcal{S}\) and \((q,l,\mu ) \in T\); there exists \(\mu ' \xRightarrow {l} \mu ''\) such that \((\mu ,\mu '') \in \mathcal{D}(\mathcal{S})\).

Theorem 1 from [ Seg95 ]
#

Given two PLTSs \(\mathcal{P}\) and \(\mathcal{P}'\), \(\mathcal{P}\sqsubseteq ^t \mathcal{P}'\) if and only if there exists a probabilistic forward simulation of \(\mathcal{P}\) by \(\mathcal{P}'\).

Proof ▶

The proof is non-trivial and detailed in Segala’s PhD.

In our setting, the most interesting implication of Theorem 1 is the soundness. We will see that the definition of \(\sqsubseteq ^t\) has some limitations, notably with respect to liveness. To solve the issue, we will introduce a stonger notion of trace distribution and strengthen probabilistic forward simulation alongside. However, the soundness proof of Segala [ Seg95 ] works at the level of \(\mathfrak {e}_{\mu ,s}\), not \(s\). This is problematic because our strengthening consists in constraining schedulers, thus, we need to adapt the proof. If \(\mathcal{S}\) is a probabilistic forward simulation then it induces a choice function \(\mathcal{C}: \mathcal{S}\times T \rightarrow Sch \times (\mathcal{S}\rightarrow [0,1])\) which maps any \((q,\mu ') \in \mathcal{S}\) and \((q,l,\mu ) \in T\) to the scheduler that induces \(\mu ' \xRightarrow {l} \mu ''\) and the witness \(w\) of \((\mu ,\mu '') \in \mathcal{S}\).

Simulation Algorithm for Schedulers Input: \(\mathcal{P}, \mathcal{P}'\) two PLTSs, \(\mathcal{S}\) a probabilistic forward simulation of \(\mathcal{P}\) by \(\mathcal{P}'\) and \(s \in Sch\) \(e, e', \mu ' \gets q_\star , q'_\star , \delta _{q_\star '}\) \(acc \gets e'\) \(t \gets s(e)\) \(t \ne \bot \) \(s_t, w_t \gets \mathcal{C}(last(e),\mu ',t)\) \(t' \gets s_t(e')\) \(t' \ne \bot \) \(e' \gets e'.lbl(t').out(t')\) \(acc \gets acc.lbl(t').out(t')\) \(t' \gets s_t(e')\) \(e', \mu ' \gets last(e'), \mathfrak {q}_{\mu ',s_t}\) \(e \gets e.lbl(t).q\) with probability \(\frac{\sum _{\mu \in \mathcal{D}(Q')}w(q,\mu )\cdot \mu (e')}{\mu '(e')}\) \(t \gets s(e)\)

Once the choice function \(\mathcal{C}\) is fixed, Algorithm 1 is a sequential probabilistic program, thus, it can be modelled as a deterministic PLTS. Of course, the validity of the different instructions of the algorithm should be proven properly, but it is not the point. The variable \(e\) encodes an execution of \(\mathcal{P}\) and \(acc\) an execution of \(\mathcal{P}'\) that simulates it. In order to extract a scheduler of \(\mathcal{P}'\) from Algorithm 1, we need to identify instructions deciding which transitions to execute in \(\mathcal{P}'\). The most obvious one is \(t' \gets s_t(e')\) when \(t' \ne \bot \), then there is \(t \gets s(e)\) when \(t = \bot \). The case where \(t' = \bot \) have to be discarded because another \(t'\) will then be picked without updating \(acc\). When \(t = \bot \) then the algorithm stops and so the scheduler on \(\mathcal{P}'\) would also return \(\bot \). After each update of \(acc\), one of the three following events will happen: (i) \(t\) is set to \(\bot \); (ii) \(t'\) is set to a non-\(\bot \) value and (iii) \(t'\) is set to \(\bot \) indefinitely. Cases (i) and (iii) correspond to scheduling \(\bot \) and case (ii) corresponds to scheduling \(t'\). Thus, the key values to compute are: \(reach(e')\) the probability of reaching a configuration where \(acc = e'\) and \(sch(e',t)\) the probability of reaching a configuration where \(acc = e\) and \(t' = t\). Knowing these, one can define a scheduler on \(\mathcal{P}'\) as

\[ s' : e' \mapsto \begin{cases} t’ \mapsto \frac{sch(e',t')}{reach(e')} \\ \bot \mapsto 1 - \frac{\sum _{t' \in T'}sch(e',t')}{reach(e')} \end{cases} \]

I am quite convinced that \(\mathfrak {t}_{q_\star ,s} = \mathfrak {t}_{q_\star ',s'}\).

0.1.2 Non-probabilistic Systems

Non-probabilistic systems can be considered as special instances of PLTSs where all transitions lead to a Dirac distribution. By identifying Dirac distributions to the unique state in their support, we can assume that non-probabilistic systems are modelled by LTS which leads to some simplifications. In particular, probabilistic forward simulation is equivalent to a simpler simulation relation. On LTS, we denote \(q \xRightarrow {l} q'\) if their exists a partial execution from \(q\) to \(q'\) whose trace is \(l\).

Definition 5 Weak Simulation
#

Lean declarations

  • Weak Simulation

Given \(\mathcal{P}\) and \(\mathcal{P}'\) two LTSs, a weak simulation of \(\mathcal{P}\) by \(\mathcal{P}'\) is a relation \(\mathcal{S}\subseteq Q \times Q'\) such that \((q_\star ,q_\star ') \in \mathcal{S}\) and, for all \((q,q') \in \mathcal{S}\) and \((q,l,p) \in T\); there exists \(q' \xRightarrow {l} p'\) such that \((p,p') \in \mathcal{S}\).

Theorem 2
#

Given two LTSs \(\mathcal{P}\) and \(\mathcal{P}'\), \(\mathcal{P}\sqsubseteq ^t \mathcal{P}'\) if and only if there exists a weak simulation of \(\mathcal{P}\) by \(\mathcal{P}'\).

Proof ▶

According to Theorem 1, it suffices to prove that there exists a weak simulation of \(\mathcal{P}\) by \(\mathcal{P}'\) if and only if there exists a probabilistic forward simulation of \(\mathcal{P}\) by \(\mathcal{P}'\). For one direction, it suffices to note that any weak simulation is a probabilistic weak simulation. For the other direction, if \(\mathcal{S}\) is a probabilistic forward simulation of \(\mathcal{P}\) by \(\mathcal{P}'\) then \(\{ (q,q') \mid \exists (q,\mu ) \in \mathcal{S}, q' \in \bar\mu \} \) is a weak simulation of \(\mathcal{P}\) by \(\mathcal{P}'\).

There is a natural injection of LTSs to PLTSs, but also a natural projection of PLTSs onto LTSs. It consists in transforming all the probabilistic non-determinism into classical non-detrminism. The projection of a PLTS \(\mathcal{P}\), denoted \(\rho (\mathcal{P})\), is the LTS whose transition are defined by \(\{ (q,l,q') \mid \exists \mu \in \mathcal{D}(Q), (q,l,\mu ) \in T \wedge q' \in \bar\mu \} \). \(\rho \) is trivially the identity on LTSs and \(\rho \) preserves the set of executions and so the set of traces. As a result, the notion of weak simulation can be lifted to PLTSs: \(\mathcal{S}\) is a weak simulation of \(\mathcal{P}\) by \(\mathcal{P}'\) if and only if it is a weak simulation of \(\rho (\mathcal{P})\) by \(\rho (\mathcal{P}')\). Since \(\rho \) is a projection on LTSs, this is consistent with the previous definition.

Theorem 3
#

Given two PLTSs \(\mathcal{P}\) and \(\mathcal{P}'\), \(\mathcal{T}\subseteq \mathcal{T}'\) only if there exists a weak simulation of \(\mathcal{P}\) by \(\mathcal{P}'\).

Proof ▶

The proof is folklore. For each execution of \(\mathcal{P}\), an execution of \(\mathcal{P}'\) can inductively be built such that they share the same trace.

0.1.3 Preserving Liveness

Our current definitions are not adapted to speak about liveness. Indeed, \(\mathcal{E}\) always contain the empty execution \(q_\star \), thus, \(\mathcal{T}\) always contain the empty trace \(\tau \). As a result, no liveness property can be satisfied against such a set of executions. However, intuition tells us that such executions should be discarded when evaluating properties because we implicitely make a progress assumption: "if a transition is enabled then a transition should be performed".

To take into account this observation, we say that an execution is maximal if it is infinite or its last state is a deadlock. Similarly, we say that a trace is maximal if it is the trace of a maxiaml execution. According the progress assumption, properties should be evaluated against the set of maximal traces. Therefore, we must develop simulation relations that preserve the set of maximal traces. The set of maximal traces is denoted \(\mathcal{T}^{\max }\).

However, weak simulation does not preserve the set of maximal traces. First, there exists a trivial weak simulation of a deadlock by any LTS. Then, since \(\tau \)-transitions can be elided, an infinite execution whose trace is \(\tau \), called a divergence, can be simulated by stuttering. We call a weak divergence any execution whose trace is \(\tau \) and which is infinite or end by a deadlock. We also say that a state weakly diverges if a weak divergence starts from it.

Definition 6 Maximal Weak Simulation
#

Given two PLTSs \(\mathcal{P}\) and \(\mathcal{P}'\), a weak simulation \(\mathcal{S}\) of \(\mathcal{P}\) by \(\mathcal{P}'\) is said to be maximal if, for all \((q,q') \in \mathcal{S}\), if \(q\) weakly diverges then \(q'\) weakly diverges.

Theorem 4
#

Given two PLTSs \(\mathcal{P}\) and \(\mathcal{P}'\), \(\mathcal{T}^{\max } \subseteq \mathcal{T}'^{\max }\) only if there exists a weak simulation of \(\mathcal{P}\) by \(\mathcal{P}'\).

Proof ▶

It suffices to adapt the proof of Theorem 3. When building an execution \(e'\) of \(\mathcal{P}'\) that simulates a maxiaml execution \(e\) of \(\mathcal{P}\), it suffices to check that the additional requirement on the simulation ensures that \(e'\) is maximal. If \(e\) contains infinitely many non-\(\tau \) labels then the construction will naturally yields an infinite execution. Otherwise, after simulating the smallest finite prefix that contains all non-\(\tau \) labels, it suffices to trigger the weak divergence preservation.

However, this solution is not satisfactory because the additional requirement asks to test for the existence of weak divergences in \(\mathcal{P}\). In practice, \(\mathcal{P}\) will be a PLTS encoding a real implementation whose size and complexity will make this search difficult. To get around this issue, simulations should rely on test that can be performed locally (e.g. checking if a transition is enabled), not globally (e.g. checking whether a divergence exists). Definition 7 Progressive Weak Simulation
#

Given two PLTSs \(\mathcal{P}\) and \(\mathcal{P}'\), a weak simulation \(\mathcal{S}\) of \(\mathcal{P}\) by \(\mathcal{P}'\) is said to be progressive if

  • for all \((q,q') \in \mathcal{S}\), if \(q\) is a deadlock then \(q'\) weakly diverges.

  • there exists \({\lt} \subseteq Q \times Q\) well-founded such that, for all \((q,q') \in \mathcal{S}\) and \((q,l,p) \in T\), if \((q,l,q')\) is elided by \(\mathcal{S}\) then \(q {\gt} p\) or \(q'\) weakly diverges.

Theorem 5
#

A weak simulation \(\mathcal{S}\) is maximal if and only if it is progressive.

Proof ▶

Suppose that \(\mathcal{S}\) is maximal. Let \((q,q') \in \mathcal{S}\) such that \(q\) is a deadlock then \(q\) weakly diverges so, by maximality, \(q'\) weakly diverges. Define \(q {\gt} p\) if there exists \(q' \in Q'\) such that \((q,q') \in \mathcal{S}\) and \(q \xrightarrow {\tau } p\) and \(\mathcal{S}\) elides it and \(q'\) does not weakly diverge. It remains to check that \({\gt}\) is well-founded. If there exists \(q_0 {\gt} q_1 {\gt} \cdots \) then \(q_0\) diverges and there exists \(q' \in Q'\) such that \((q,q') \in \mathcal{S}\) and \(q'\) does not weakly divrege which contradicts the maxiamlity of \(\mathcal{S}\).

Suppose that \(\mathcal{S}\) is progressive. \((q,q') \in \mathcal{S}\) and \(q\) weakly diverges. If \(q \xRightarrow {\tau } p\) and \(p\) is a deadlock then \(q' \xRightarrow {\tau } p'\) such that \((p,p') \in \mathcal{S}\), thus, \(p'\) weakly diverges and so does \(q'\). If \(q\) diverges then \(q'\) weakly diverges or there exists \(q' \xRightarrow {\tau } p'\) such that \(p'\) simulates a suffix of \(q\)’s divergence by stuttering contradicting \({\gt}\) well-foundedness.
